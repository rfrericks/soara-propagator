# Submissions

This folder holds **normalized, structured submissions** — one Markdown file per
contribution, built from `../../../templates/submission.md` or the matching
section template, with the contributor's wording preserved.

Raw, unedited material (pasted email, Word docs, PDFs, photos) goes in
`_inbox/` first, then gets normalized into a file here during assembly.

Suggested filename:

`section-author-callsign-short-title.md`
