# Editorial Style

## Voice

Use a friendly, practical club voice. Explain technical subjects clearly,
welcome newer operators, recognize volunteers, and end calls to action with a
specific next step.

## Names and Callsigns

- On first mention, use `Full Name, CALLSIGN`.
- Later mentions may use first name or callsign.
- Verify every callsign before publication.
- Preserve the contributor's preferred sign-off when practical.

## Dates, Times, and Locations

- Use an unambiguous date: `Monday, June 15, 2026`.
- Include both start time and location for events.
- Use `9:00 AM-noon` consistently.
- Verify the calendar immediately before publication.

## Links and Technical Claims

- Use descriptive link text instead of a bare URL where possible.
- Test every link.
- Attribute technical recommendations to the author.
- Check current regulations and event rules before publishing them.

## Photos

- Include a caption and photographer credit.
- Identify visible members when permission and names are available.
- Do not publish sensitive personal information.
- Prefer images that demonstrate club participation or clarify an article.

## Editing

- Keep the author's character while correcting clarity and mechanics.
- Break long technical articles into descriptive subsections.
- Spell out uncommon abbreviations on first use.
- End recurring reports with the next event date and contact or sign-off.
